# CodeAlpha Web Scraping Project

## Overview

This project was completed as part of the CodeAlpha Data Analytics Internship.

The project demonstrates web scraping using Python, Requests, BeautifulSoup, and Pandas. Data was collected from the Books to Scrape website, a practice website designed for web scraping.

## Objective

The objective of this project is to:

- Extract structured information from web pages
- Navigate multiple listing pages
- Collect and organize book information
- Clean scraped data
- Create a reusable CSV dataset

## Data Collected

The scraper collects the following information:

- Book Title
- Price
- Rating
- Availability
- Book URL

The final dataset contains **1,000 books**.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
